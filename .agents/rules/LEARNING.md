# Learning\n\n- When building the `aarch64-unknown-linux-musl` target via `cross` (as configured in `.github/workflows/build.yml`), avoid explicitly setting the linker (`CARGO_TARGET_AARCH64_UNKNOWN_LINUX_MUSL_LINKER`) to a GNU GCC binary (`aarch64-linux-gnu-gcc`). The `cross` container already uses the appropriate pre-configured musl compiler suite. Overriding it causes linker missing errors (`os error 2`) and build failure.
- Added root=/dev/ram0 rw to Universal ISO GRUB config and -boot d to the QEMU test command, fixing the VFS unable to mount root fs kernel panic in the boot validation step.
- In '.github/workflows/build.yml', ensure that the 'cross' executable is installed in all jobs that invoke it (e.g., both the 'build' and 'test' jobs), otherwise the workflow will fail with 'cross: command not found'.
